# Getting started with kol-quest

Scrape all KOL wallet data from kolscan.io leaderboard + GMGN smart money

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/kol-quest.git
cd kol-quest
```

Available commands:

| Command | Runs |
|---|---|
| `npm run dev` | `cd site && npm run dev` |
| `npm run build` | `cd site && npm run build` |
